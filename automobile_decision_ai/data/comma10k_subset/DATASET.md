# Dataset Attribution

This project includes a curated subset of the `comma10k` dataset.

- Source repository: [https://github.com/commaai/comma10k](https://github.com/commaai/comma10k)
- Organization: comma.ai
- License: MIT

The subset contains:

- 60 road-scene images
- 60 matching semantic segmentation masks

The original `comma10k` dataset defines these semantic classes:

- road
- lane markings
- undrivable
- movable
- my car

The files in this folder are included for educational and project-demo use under the original MIT license terms.
